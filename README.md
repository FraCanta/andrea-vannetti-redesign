# andreavannetti.dev

Portfolio personale — Sviluppatore Web Freelance nel Chianti.

## Stack

- **Framework:** Next.js 14 (App Router) + TypeScript
- **Styling:** Tailwind CSS
- **Animazioni:** Framer Motion
- **Icone:** Lucide React + React Icons
- **Deploy:** Vercel

## Setup

```bash
npm install
npm run dev
```

Il sito sarà disponibile su `http://localhost:3000`.

## Font

Scarica [Clash Display](https://www.fontshare.com/fonts/clash-display) (Medium, Semibold, Bold) in formato `.woff2` e posiziona i file in `public/fonts/`.

## Deploy

Il progetto è configurato per Vercel. Collegalo alla repo e il deploy è automatico.
